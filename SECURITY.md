# Política de Segurança

## Reportando vulnerabilidades

Se você descobrir uma vulnerabilidade de segurança no **GameShelf**, **não abra uma issue pública**.

Em vez disso, utilize o recurso de **Private Vulnerability Reporting** (Security Advisories) na aba **Security** do repositório no GitHub para relatar o problema diretamente aos mantenedores.

Ao enviar um relato, inclua:

- Descrição clara do problema e do impacto potencial.
- Passos para reproduzir a vulnerabilidade.
- Versão ou commit em que o comportamento foi observado.

## Cuidados com dados pessoais e credenciais

- Nunca publique chaves pessoais da API do SteamGridDB, tokens de acesso, senhas, arquivos `.env` ou bancos de dados locais (`library.db`) em issues, Pull Requests ou comentários públicos.
- Caso suspeite que alguma credencial foi exposta acidentalmente em um commit ou issue, revogue/regenere a chave imediatamente no serviço de origem antes de notificar os mantenedores.
